# Security policy

## Supported versions

Only the latest release gets security fixes. Older releases are not supported.

## Report a vulnerability

Do not open a public issue for a security problem.

1. Open the [Security tab](https://github.com/harvinder-power/hubspot-desktop/security) of this repo.
2. Select "Report a vulnerability".
3. Describe the problem, the affected version, and the steps to reproduce it.

GitHub keeps the report private between you and the maintainers.

## What to leave out

Do not include real tokens, session cookies, or customer data in a report.
Use placeholder values instead.

## Scope

This project is unofficial and is not affiliated with HubSpot, Inc.
Report problems in the HubSpot service itself to HubSpot, not here.
